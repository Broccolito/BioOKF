03 — Root cause

Canonical vs alias gene resolution

26 of the 85 disagreements are genes, and Claude wins nearly all. Codex resolves a symbol to a different gene that merely lists it as an alias, rather than the canonical gene whose official symbol matches. Claude matches exact name first and flags multi-hits.

05 — Cross-pollinate

What to borrow from each

← from Codex

  1. Synonym-as-identifier. Pull rsIDs / CURIEs out of a node's synonyms and match as identifiers — how Codex caught R620W→rs2476601, ENT3→SLC29A3 that Claude missed.
  2. Rich edge evidence — keep per-relationship source ids, sources, and stat keys.
  3. Audit & reproducibility harness — audit-run, --fail-on-query-warning, topology preservation, override verification.
  4. A curation-override file as the home for low-confidence decisions a human signs off.

← from Claude

  1. Autonomous LLM adjudication (id-verified) — +260 nodes at 96% precision, 0 false positives; the single biggest lever.
  2. Exact-name-first canonical gene resolution with ambiguity flagging — kills the alias-collision errors.
  3. Guard-word splitting — keep the node instead of dropping it.
  4. Disambiguation discipline — refuse generic/family terms (PI3K, cyclooxygenase) rather than force a single node.
06 — The path forward

One waterfall, best of both

In confidence order — deterministic and cheap first, LLM only for the residue, humans only for the tail.

Exact identifier — from xref and from synonymscodex
Exact canonical name — name beats synonym, multi-hit ⇒ ambiguousclaude
Exact synonym + disambiguation guard — accept only if unique and not a family/generic termmerge
LLM adjudication of the ambiguous/not-found residue, id-verified before applyclaude
Curation-override file for the low-confidence tail; auto-apply only high-confidencecodex
SPOKE-duplicate canonicalization — collapse CHEBI/inchikey & GO/Pathway twins so "both valid" splits vanishnew
Edge layer — Codex's rich evidence + a distinct related_in_spoke status for family-broadened matches, keeping strict families as the "agrees" barnew
Wrap in Codex's audit harness + --fail-on-query-warning for reproducible runscodex

Net: Codex's rigor and synonym/edge techniques as the chassis, Claude's LLM adjudication and canonical-name resolution as the engine — >70% of-mappable coverage at Claude's precision, with Codex-grade auditability.
