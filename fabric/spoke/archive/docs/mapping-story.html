01The problem

Narrative knowledge, meet structured ground truth

An LLM can read a paper and assert “PTPN22 associated_with type 1 diabetes.” But is that claim already in a curated biomedical knowledge graph? Does the graph agree, or does it hold the opposite? Answering that means mapping the LLM's entities and relationships onto SPOKE — the UCSF Baranzini Lab's knowledge graph.

Source · BioOKF

The LLM-curated graph

A git-shippable bundle of typed concept documents authored by an agent from literature. Closed vocabulary, human-readable names.

28 node types 35 predicates names, not CURIEs
Target · SPOKE

The curated ground truth

A production biomedical knowledge graph: Genes, Compounds, Diseases, Variants, Proteins and the relationships between them, from dozens of source databases.

42 node labels 129 edge types 40M+ nodes
The catch that shaped everything

The benchmark bundle — benchmark-biored, 2,550 nodes and 5,360 edges — carries almost no CURIE cross-references on its biomedical entities. Only publications have PMIDs. So mapping can't lean on identifiers; it hinges on matching names and synonyms, constrained by type. That single fact is why both agents converged on a “waterfall,” and why the hard cases needed judgment.

02The method

A confidence waterfall

Both agents built the same shape: cheap, high-precision matches first; expensive judgment only for what falls through. Each node runs the tiers top to bottom and stops at the first confident hit.

1

Exact identifier

A CURIE (or an rsID hiding in the synonyms) that is a SPOKE identifier.

conf 1.00
2

Exact canonical name

Index-backed name match — the official symbol, not an alias.

conf 0.98
3

Case-insensitive / synonym

Normalized name & synonym equality, greek letters and punctuation folded.

conf 0.90–0.95
4

LLM adjudication the residue

An agent queries SPOKE, weighs candidates, and either commits or declines — every id then verified to exist.

conf ≤0.88
5

Curation & review queue

The low-confidence tail, left for a human or curator to sign off — never auto-applied.

reviewed

Then: do the edges agree?

For any edge whose both endpoints mapped, look for a SPOKE relationship in the predicate's family. The verdict is the scientific payload.

agrees_with_spoke

SPOKE has a matching relationship. Its evidence is attached.

contradicts_spoke

The claim is a not_* negative, yet SPOKE positively asserts it.

found_but_unmapped_predicate

A SPOKE edge exists, but of a different relationship family.

not_found_in_spoke

Both nodes mapped, but no relationship connects them.

05The payoff

What SPOKE confirmed — and contradicted

The point of grounding isn't a bigger graph; it's judgment. When a paper reports a negative finding that SPOKE's curated evidence positively asserts, that tension is worth a scientist's attention. These surfaced automatically.

HFE not_associated_with hemochromatosis
SPOKE: ASSOCIATES_DaG — HFE is the classic hemochromatosis gene.
C2 · C3 · CFB not_associated_with age-related macular degeneration
SPOKE: ASSOCIATES_DaG — complement genes are landmark AMD associations.
GCK · GLP1R · HNF4A not_associated_with type 2 diabetes
SPOKE: ASSOCIATES_DaG — all established T2D genes.
sevoflurane not_causes convulsions
SPOKE: CAUSES_CcSE — a documented adverse effect.

These are the negatives worth a second look — not errors, but places where a single paper's finding runs against the weight of curated evidence. The combined map surfaced 14 such contradictions and 197 agreements, each carrying SPOKE's supporting evidence.

06The synthesis

The optimized combined approach

Neither agent's design is the answer alone. Codex's rigor and synonym/edge techniques make the chassis; Claude's LLM adjudication and canonical-name resolution make the engine. One waterfall, best of both — cheap and deterministic first, LLM for the residue, humans only for the tail.

One waterfall, eight moves

Exact identifier — from xref and synonymsborrow · codex
Extract rsIDs / CURIEs buried in synonyms and match as identifiers. Wins named variants for free.
Exact canonical nameborrow · claude
Name index first; a name hit beats a synonym hit; multiple hits ⇒ ambiguous. Kills the alias-collision errors.
Exact synonym + disambiguation guardmerge
Accept a synonym match only when it's unique and the term isn't a family/generic. Keeps ENT3→SLC29A3, blocks cyclooxygenase→one gene.
LLM adjudication of the residue — id-verifiedborrow · claude
Agents resolve ambiguous / not-found nodes against live SPOKE; every returned id is verified to exist before it's applied.
Curation-override file for the tailborrow · codex
Low-confidence decisions await human sign-off; only high-confidence LLM calls auto-apply.
Canonicalize SPOKE duplicatesnew
Collapse CHEBI/inchikey and GO/Pathway twins — that's what most “both valid” splits actually are.
Edge layer: rich evidence + a related_in_spoke statusnew
Keep Codex's per-relationship evidence; add a distinct partial-match status for family-broadened predicates instead of loosening “agrees”.
Wrap in the audit harnessborrow · codex
Topology preservation, override verification, --fail-on-query-warning for reproducible runs.
Codex's chassis, Claude's engine → >70% of-mappable coverage at Claude's precision, with Codex-grade auditability.
